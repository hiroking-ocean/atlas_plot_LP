プライバシーポリシー

最終更新日：2026年11月2日

Atlas Plot は、地図上に描いた内容をお使いのパソコンに保存する Windows アプリです。アカウント登録は不要で、プロジェクトの内容を開発者のサーバーへ送ることはありません。地図を表示するときと地名を検索するときだけ、地図サービスへ通信します。

要点

  • アカウント登録・ログインは不要です
  • プロジェクトと図面は、ご自身が選んだ場所にだけ保存されます
  • 開発者のサーバーへ、利用状況や作成内容を送信しません
  • 通信するのは、地図の表示（国土地理院・OpenStreetMap）と地名検索（国土地理院）だけです
  • 広告・利用状況の解析・クラッシュ情報の自動送信はありません

1. 基本方針

Atlas Plot（以下「本アプリ」）は、Windows 向けのデスクトップアプリです。利用にあたってアカウントの作成やログインは必要ありません。

本アプリは、利用者が作成したプロジェクトの内容（点・線・図形・テキスト・図面画像など）を、開発者や第三者のサーバーへ送信しません。広告 SDK、行動トラッキング、利用状況の解析、クラッシュ情報の自動送信も組み込んでいません。

開発者は、本アプリを通じて、氏名・メールアドレス・端末の現在地など、個人を特定できる情報を取得しません。

2. お使いのパソコンに保存される情報

本アプリは、次の情報をお使いのパソコン内に保存します。いずれも開発者へは送信されません。

  • プロジェクト：利用者が選んだフォルダに、project.sqlite（地図上の点・線・図形・テキスト・属性など）と assets フォルダ（取り込んだ図面画像）として保存します。
  • アプリの設定：スナップの ON/OFF、座標の表示形式、最後に開いたプロジェクトの場所を、アプリ用のローカルデータフォルダ（user-settings.json・last-project.json）に保存します。
  • 作業用の一時ファイル：プロジェクトを開いている間、安定して編集・保存するために、パソコンの一時フォルダへ作業用のコピーを作成します。プロジェクトを閉じると削除します。
  • 編集中を示すロックファイル：同じ場所のプロジェクトを複数の人が同時に編集して壊すことを防ぐため、プロジェクトと同じフォルダに atlas-edit.lock.json を作成します。このファイルには、Windows のユーザー名（ドメイン名または PC 名付き）、編集セッション ID、最終更新時刻が含まれます。プロジェクトを閉じると削除しますが、共有フォルダに置いている場合は、同じフォルダを開く他の利用者から内容が見えることがあります。

3. 外部サービスへの通信

本アプリは、地図の表示と地名検索のために、次の外部サービスへインターネット経由でアクセスします。プロジェクトの内容や図面画像は送信しません。

3.1. 国土地理院（地理院タイル）

背景地図（淡色地図）の画像を cyberjapandata.gsi.go.jp から取得します。表示中の地図の範囲とズームレベルに対応するタイルを要求するため、お使いのパソコンの IP アドレスと、閲覧している地図の範囲が国土地理院のサーバーに届きます。

国土地理院ウェブサイトの利用規約 および 地理院タイルの利用案内 が適用されます。

3.2. 国土地理院（住所・地名検索）

ヘッダーの検索欄に入力した住所・地名の文字列を、msearch.gsi.go.jp の住所検索 API へ送信し、候補の位置を取得します。検索欄に入力しない限り、この通信は行われません。入力した文字列は国土地理院のサーバーへ送られるため、個人情報や機密情報は入力しないでください。

3.3. OpenStreetMap

背景地図に OpenStreetMap を選んだとき、地図画像を tile.openstreetmap.org から取得します。国土地理院の場合と同様に、お使いのパソコンの IP アドレスと、閲覧している地図の範囲が OpenStreetMap Foundation のサーバーに届きます。

OpenStreetMap Foundation プライバシーポリシー および OpenStreetMap の著作権とライセンス が適用されます。

3.4. Microsoft Store・Windows

本アプリは Microsoft Store を通じて配布します。インストール、更新、購入、評価・レビューの処理は Microsoft が行い、端末やアカウントの設定に応じて、インストール状況や診断情報を Microsoft が収集することがあります。Microsoft のプライバシーに関する声明 が適用されます。開発者は、個人を特定できる形でこれらの情報を取得しません。

4. 書き出したファイル

PNG・PDF として書き出した画像には、地図の出典表示、取り込んだ図面、作図した内容が含まれます。書き出したファイルは、利用者が指定した場所に保存されるだけで、本アプリが自動で送信することはありません。ファイルを他の人へ渡すときは、含まれている内容をご確認ください。

5. 利用目的・第三者への提供

開発者は、本アプリを通じて利用者の個人情報を取得しないため、その利用や第三者への提供はありません。

前項の地図サービスへの通信は、利用者のパソコンから各サービスへ直接行われるもので、開発者のサーバーを経由しません。各サービスでの情報の取扱いは、それぞれのポリシーに従います。

お問い合わせのメールをいただいた場合は、返信、ご要望・不具合への対応、品質改善のためにだけ、メールアドレスと内容を利用します。法令に基づく場合を除き、本人の同意なく第三者へ提供しません。

6. 保存期間・削除

プロジェクトのファイルは、利用者が削除するまで保存先に残ります。アプリをアンインストールしても、利用者が選んだ保存先のプロジェクトは削除されません。不要になったときは、プロジェクトのフォルダを削除してください。

アプリの設定ファイル（user-settings.json・last-project.json）は、アプリ用のローカルデータフォルダにあります。アンインストール後も残る場合は、そのフォルダを削除してください。

お問い合わせでいただいたメールは、対応の完了後、必要な期間保管してから削除します。

7. 子どものプライバシー

本アプリは、利用者の年齢を問わず、個人情報を取得しません。お子さまの利用について心配な点がある保護者の方は、下記の連絡先までご連絡ください。

8. ポリシーの変更

本アプリの機能の変更や法令の改正に応じて、本ポリシーを変更することがあります。変更するときは、このページに内容と最終更新日を掲載します。通信先や取得する情報の種類が変わるなど重要な変更があるときは、アプリのリリースノートなどでもお知らせします。
